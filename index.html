yutu-local

yutu-local is a desktop command-line configuration used by its operator to manage their own YouTube channels. It uses YouTube API Services and requires the channel operator to authorize access in Google.

With that authorization, the local tool can upload videos and timed captions, update publishing details, and schedule release on YouTube. Separately authorized read-only commands can retrieve channel performance reports.

This site explains how the local tool handles Google data. Review the privacy policy and terms of use before authorizing. Authorize only an account and channel you manage.
