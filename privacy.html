Privacy policy

November 14, 2026

Data the tool uses

yutu-local uses YouTube API Services. The operator signs in and consents on Google’s site. The local tool receives OAuth tokens. It reads channel and video identifiers, video metadata, visibility and release settings, and caption track details. It sends the selected videos, captions, and publishing settings to YouTube only when the channel operator requests those actions. Separately authorized reporting can read channel performance data such as views, watch time, and traffic sources.

Storage and sharing

The Mac running the tool stores its OAuth tokens in local files with restricted access. Publishing receipts and requested reports may contain copies of YouTube API data and are stored in the operator’s local workspace. The tool uses this data for channel management, verification, and reporting. Authorized requests go to Google and YouTube. The documentation site receives no YouTube tokens or uploaded media and uses no tracking added by the operator. GitHub Pages hosts the site and logs visitor IP addresses for security, as explained in the GitHub Privacy Statement. Google's handling of data is described in the Google Privacy Policy.

Revoke access or remove local data

Remove yutu-local from your Google Account’s third-party permissions to revoke access. You can also remove the corresponding token, publishing receipts, and downloaded reports from the Mac. Revoking access does not delete content already saved to YouTube. For help removing local data or questions about this policy, use the support contact listed on the app’s Google authorization screen.
